# 專案章程

## 目的

以最小可維護的原生 iOS 架構，讓使用者在 iPhone／iPad 離線完成課程閱讀、題庫練習、錯題複習、模擬測驗、收藏／筆記與學習進度追蹤。

## 必須做到

1. 題目、正確答案、解析、另外解答與公開來源分層呈現。
2. 同一份 SwiftUI 程式支援 iPhone Tab 與 iPad Sidebar。
3. 題庫與 App 一次綁定，更新題庫只能發布新版 App。
4. App 更新不得覆蓋學習紀錄；資料 migration 失敗須保留上一份可讀資料並阻止破壞性寫入。
5. 公開 GitHub 不得洩漏原始題庫、授權文件、個資、內網與任何憑證。
6. 每次內容／App 發布均可追溯版本、題數、來源狀態、QA 與核准人。

## MVP 不做

- 線上題庫更新、遠端 feature flag、會員帳號、跨裝置同步。
- Web／Android／後台管理系統、Telegram、StoreKit、廣告、分析 SDK。
- 起重機操作模擬、AR／3D、UGC 或社群功能。
- 自動改寫正式答案；AI／OCR 只能產生待審資料。

## 成功標準

- 真機 iPhone 與 iPad 可全程離線使用核心功能。
- 安裝 A 版建立學習紀錄後，以較高 build 安裝 B 版，進度、錯題、收藏、筆記與考試紀錄完全保留。
- 題庫 validator 零錯誤，所有穩定 ID 唯一且未被重用。
- 公開資料 gate、unit tests、iPhone／iPad UI smoke 與無障礙 gate 通過。
- App Store metadata、隱私政策、Support URL、內容權利與 signed archive 完整。

## 決策權

涉及正式產品名稱、價格、法律聲明、題庫答案爭議、內容授權、Apple Account Holder 操作或公開發布的不可逆行動，由 Owner 最終核准。一般檔名、程式結構、CI 與暫定 metadata 由開發流程先行定義，不作為停工理由。
