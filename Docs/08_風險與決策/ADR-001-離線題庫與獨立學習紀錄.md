# ADR-001：離線題庫與獨立學習紀錄

## 背景

產品不提供線上題庫更新，內容更新只能透過 App 發版；同時正常更新 App 不得覆蓋學習紀錄。

## 決策

- 題庫與圖片放 App bundle，作為只讀、versioned content。
- 使用者學習紀錄放 Application Support 的 SwiftData store。
- 題庫與 UserStore 不共用檔案、schema 或 replace operation。
- stable question ID 是兩者唯一連結；題目下架不刪紀錄。
- 所有 persistence 變更必須通過 upgrade／failure test。

## 選擇理由

比「首次啟動把題庫複製到可寫 DB 再整庫替換」更少 migration 與原子切換程式；比 server 更新、CloudKit 或會員同步更符合最小開發量與零營運服務目標。

## 代價

- 內容錯誤必須等 App 審核／更新，無法即時 hotfix。
- App bundle 可能較大。
- 使用者刪除 App 後無 MVP 內建復原能力。
- 題庫 schema 必須 forward compatible，舊紀錄需處理下架題。

## 否決方案

- 遠端 full/delta 題庫：增加 server、簽章、下載、回復、網路與維運成本。
- 把學習紀錄塞進題庫 DB：App 更新時極易覆蓋／重建使用者資料。
- 只用 UserDefaults 保存全部紀錄：資料量、migration、query 與 failure handling 不如獨立 store 清楚。
