# 產品需求書

## 產品定義

| 欄位 | 內容 |
| --- | --- |
| 正式名稱 | 三噸以上固定式起重機考照學習系統 |
| 顯示名稱 | 起重機考照通 |
| 英文工作名 | 3T Crane Study |
| 主要使用者 | 準備三噸以上固定式起重機考照的繁體中文使用者 |
| 使用情境 | 通勤、課前／課後複習、離線練題、考前模擬 |
| 價值 | 題目、解析、來源、錯題與進度集中在一個離線 App |

## MVP 導覽

### iPhone

底部五分頁：首頁、課程、測驗、紀錄、我的。錯題、法規、筆記、收藏與版本資訊從首頁／我的進入。

### iPad

使用 `NavigationSplitView` 持續側欄；右側 detail 顯示相同 feature view，選單切換時不殘留上一個題目導覽堆疊。

## 四種學習流程的邊界

| 流程 | 答案揭露 | 是否計入作答 | 主要用途 |
| --- | --- | --- | --- |
| 課程／複習 | 進入題目即分段顯示答案、解析、另外解答與來源 | 否 | 按官方題序閱讀、理解與記憶 |
| 題庫測驗 | 選擇 A–D 後立即揭露 | 是 | 主動回想、即時訂正與建立錯題 |
| 錯題複習 | 重新選答後立即揭露 | 是 | 對待補強題反覆練習並更新掌握狀態 |
| 模擬測驗 | 交卷前一律隱藏，交卷後才揭露 | 是 | 限時抽題、計分與考試結果檢討 |

課程／複習與題庫測驗不得共用同一個「必須先選答案」的互動流程。兩者可以共用題庫模型、答案呈現元件、收藏、筆記與穩定題目 ID，但畫面狀態與紀錄語意必須分開。

## 模擬測驗規格

- 正式模擬：單一級學科 80 題、100 分鐘，每題 1.25 分，答錯不倒扣。
- 抽題組成：06100 專業題 64 題；90006、90007、90008、90009 四個共同科目各 4 題，共 16 題。
- 快速練習：全題庫隨機 10 題、10 分鐘，只是短時練習，畫面不得稱為正式模擬。
- 正式模擬與快速練習均於交卷前隱藏答案；允許空白題交卷，時間到自動交卷，離開 App 可恢復未完成快照。
- 規格依據：[技能檢定中心－學術科測試檢定方式](https://www.wdasec.gov.tw/News_Content.aspx?n=611E645F4BAB689F&s=C01442902F63E8F8&sms=47C68486FEC19CA4)、[四項共用工作項目抽題比例公告](https://www.wdasec.gov.tw/News_Content.aspx?n=25D08F3407C71E8F&s=5A79A08661B15374&sms=1BE761BDBCE7C913)。發版前仍須依官方最新公告複核。

## 不應沿用設計板的項目

「下載管理」不適用於題庫一次綁定，改為「版本與內容說明」；「通知訊息」只做本機學習提醒，不做伺服器推播；「我的帳戶」改為「我的」，不要求登入。

## 非功能需求

- 冷啟動後離線可進入全部核心畫面。
- 3,000–10,000 題仍可在一般裝置順暢搜尋／篩選。
- Dynamic Type 至 Accessibility XXXL、VoiceOver、Increase Contrast、Reduce Motion。
- 支援直向；iPad 支援分割視窗，iPhone 橫向是否開放由首輪 UI QA 決定。
- 不收集使用資料、不內嵌追蹤／廣告 SDK。
- 顯示 App version、build、content version、來源查核日期與免責說明。

## 待題庫治理完成後確認

- 正式科目／章節、題型與及格規則；已確認題數、時間與共同科目抽題比例。
- 題庫是否含圖片、表格或公式，以及對應無障礙替代文字。
- 法規與安全標準來源、授權、查核日期與更新責任。
