# 題庫資料規格

## 公開發行包

唯一 App 內容權威為 Xcode build resource 所引用的 `Content/Releases/question-bank-<version>.json`。正式檔只在發 App 時更新，不設 manifest API、下載 URL 或 delta。

```json
{
  "schemaVersion": 1,
  "contentVersion": "1.0.0",
  "subjects": [],
  "chapters": [],
  "questions": []
}
```

Machine-readable schema 位於 `Content/Schema/question-bank.schema.json`，合成 fixture 位於 `Content/Fixtures/question-bank.synthetic.json`。

## 題目欄位

```json
{
  "id": "crane-safety-0001",
  "publicCode": "CR-SF-0001",
  "subjectId": "safety",
  "chapterId": "safety-inspection",
  "kind": "choice",
  "prompt": "題幹",
  "options": ["A", "B", "C", "D"],
  "answerIndex": 0,
  "answer": "A",
  "explanation": "完整解析",
  "alternativeAnswer": "",
  "publicSource": "可公開來源名稱",
  "publicSourceUrl": "https://example.invalid",
  "publicSourceCheckedAt": "2026-08-10",
  "accuracyStatus": "checked",
  "rightsStatus": "cleared"
}
```

## 穩定性規則

- `id` 與 `publicCode` 唯一，發布後不可改派給其他題目。
- 選擇題固定 4 個互不重複選項，`answerIndex` 為 0–3。
- `answer` 是可讀答案；計分權威為 `answerIndex`。
- `explanation` 不得只是複製答案；無可靠解析時留空。
- `alternativeAnswer` 只有經治理確認等價時填入。
- 外部來源只允許 HTTPS；內部原始檔名、路徑、頁碼、審查者資料不得進此 JSON。
- App decoder 對未認識的 optional 欄位保持 forward compatible，但必要欄位缺失必須拒絕整包。

## 私有治理台帳

下列資料只保存在 `PrivateResources/` 或 repo 外：原檔 SHA-256、權利依據、匯入來源檔／頁／題號、OCR 信心、答案衝突、審查者、核准時間與修訂前後差異。公開 release 只保留可公開來源與權利狀態。

OCR、逐題核對、答案驗證、公開來源與解析的完整程序見 [[OCR與逐題審查流程]]。

## 內容發布 gate

1. 原始檔與授權可追溯。
2. OCR／人工文字與原稿一致。
3. 正解、選項、解析、另外解答、來源分層。
4. 重複題、穩定 ID 與 referential integrity 通過。
5. `accuracyStatus=needs-review`／`deprecated` 不進可作答清單。
6. 產生題數、科目數、SHA-256 與變更摘要。
7. `python3 Scripts/ci/validate_question_bank.py` 通過。
8. App unit／UI／upgrade persistence 測試通過並由 Owner 核准。

## 題庫收件狀態

2026-08-10 已將題庫 PDF 收入 `PrivateResources/QuestionBank-Inbox/`。檔案共 38 頁、A3 橫式、雙頁掃描且無文字層，必須先做切頁 OCR 與逐題人工核對。原檔、OCR 及私有來源定位均不加入 Git 或 Xcode；內容權利、正式科目／題數與抽題規格仍待審查完成後確認。
