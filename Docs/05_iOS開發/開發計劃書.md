# 3Tcrane iOS 開發計劃書

## 執行摘要

採原生 SwiftUI Universal App，以 Taiwan_Wtsbot 已驗證的學習流程與題庫治理為參考，刪除所有線上服務與商務模組。題庫是只讀 App resource；學習紀錄是獨立 SwiftData store。這是最小開發量、最低營運成本，同時能滿足 App 更新保留紀錄的方案。

## 工作分解

| 階段 | 主要工作 | 驗收產物 | 預估 |
| --- | --- | --- | --- |
| 0 治理與輸入盤點 | Obsidian、公開 repo、UI／題庫 inbox、權利邊界 | 本文件框架、CI gate、素材清單 | 已完成第一版 |
| 1 App 骨架 | Xcode project、DesignSystem、iPhone Tab／iPad Sidebar、合成資料 | 兩種裝置可導覽、unsigned Release build | 3–5 工作日 |
| 2 題庫核心 | Codable schema、bundle repository、科目／章節、練習、答案／解析／來源 | 合成／候選題庫完整流程 | 5–8 工作日 |
| 3 學習功能 | SwiftData、錯題、收藏、筆記、進度、模擬考 | 離線核心 MVP | 7–10 工作日 |
| 4 更新保護 | migration、A→B upgrade、orphan／revision、failure safety | 更新不覆蓋紀錄證據 | 3–5 工作日 |
| 5 正式內容 | 私有來源盤點、OCR／校對、來源／授權、發行 JSON | governed content v1.0.0 | 依題量另估 |
| 6 QA／上架 | 無障礙、效能、真機、Privacy／Support、signed archive、TestFlight | Release Candidate | 5–8 工作日 |

程式 MVP 約 23–36 個工作日；正式題庫治理不應與程式工期混算，題數與原稿品質到位後再估。各階段可獨立驗收，未取得正式題庫時使用合成資料持續開發，不停工。

## 里程碑 gate

### M1 可導覽骨架

- App ID／名稱／版本暫定值建立。
- iPhone／iPad 共用畫面與 DesignSystem。
- GitHub PR＋CI 完成第一個 Xcode build。

### M2 可學習 MVP

- 課程、題庫、錯題、模考、紀錄、我的。
- 答案、解析、另外解答、來源清楚分段。
- 全功能離線，無登入／伺服器。

### M3 更新安全

- A 版生成完整紀錄，B 版保留所有資料。
- 內容缺題／修題與 migration 失敗不刪資料。
- 真機更新驗證納入 release evidence。

### M4 正式內容 RC

- 題庫來源、答案、權利、重複、ID 與版本全數核准。
- 正式題庫不含私有來源定位，公開 repo gate 全綠。

### M5 TestFlight／App Store

- iPhone／iPad 真機、Accessibility、效能、Privacy Manifest、metadata、support/privacy URL、archive/codesign。
- Owner 核准後才上傳；TestFlight 驗證完成後才提交 App Review。

## 最小 Xcode target

- `ThreeTCraneStudy` App target。
- `ThreeTCraneStudyTests` unit／migration tests。
- `ThreeTCraneStudyUITests` iPhone／iPad smoke。
- 不建立 Widget、Extension、StoreKit config、server client 或第三方 package。

## 主要依賴與並行條件

- App 程式可用 synthetic fixture 立即開始。
- 題庫到位後由獨立內容線盤點，只有 governed release 進 App。
- 高解析素材未到位不阻塞；先用 SF Symbols／SwiftUI，App Icon RC 前補齊。
- Apple metadata 可先用本計畫暫定值；只有開通服務、付費協議、憑證與正式提交需 Owner 操作／同意。

## 完成定義

功能、資料保護、公開倉庫安全、內容權利、iPhone／iPad QA 與 Apple 提交資料必須同時通過；只在 simulator 能操作或只產生 archive 不等於完成。
