# 開發環境盤點

## 已確認

| 項目 | 版本／狀態 | 判定 |
| --- | --- | --- |
| 主機 | Apple Silicon `arm64` | 可開發 iOS |
| macOS | 26.5.2 (25F84) | 可用 |
| Xcode | 26.6 (17F113) | 可用 |
| Swift | 6.3.3 | 可用；專案語言模式先採 Swift 5 相容，逐步開 strict concurrency |
| Git | 2.50.1 Apple Git | 可用 |
| Node／npm | 22.22.0／10.9.4 | 只供參考腳本；MVP 不以 Node 作 App runtime |
| Ruby | 4.0.6 | 非必要，不導入 CocoaPods／Fastlane |
| SwiftLint | 未安裝 | 非阻塞；首版以 compiler warnings／SwiftFormat 決策後再評估 |
| xcbeautify | 未安裝 | 非阻塞，CI 保留原始 xcodebuild log |
| GitHub 遠端 | SSH URL 可連、無 refs | 空倉庫，可在治理完成後首次發布 |

## Simulator

- iOS 26.1：iPhone 17 Pro／Pro Max、iPhone 16e、iPad Pro／mini／Air／A16，另有 Taiwan_Wtsbot 專用 QA 裝置。
- iOS 26.5：iPhone 17 系列、iPad Pro、iPad mini、iPad Air 13-inch M4／11-inch M4、iPad A16。
- watchOS 26.5 runtime 顯示 unavailable；本專案不支援 watchOS，無阻塞。

最小本機矩陣：專用 `3Tcrane iPhone QA` 與 `3Tcrane iPad QA`（iPad Air 13-inch M4），皆使用 iOS 26.5；另以現有 iOS 26.1 runtime 做前一小版本相容。兩台專用 simulator 的核心導覽／作答 UI smoke 已通過。送審前仍需一台實體 iPhone 與一台實體 iPad。

## 建議目標設定

| 設定 | 值 |
| --- | --- |
| Deployment target | iOS／iPadOS 17.0 |
| Device family | iPhone + iPad (`1,2`) |
| UI | SwiftUI lifecycle |
| Persistence | SwiftData |
| Orientation | iPhone 首版直向；iPad 直／橫向與多工 |
| Signing | Automatic signing；Team／profile 不寫入公開文件 |
| Dependencies | Apple frameworks only |

## 發布前仍需檢查

- Apple Developer membership／Agreements 是否有效。
- `tw.tauruswinner.crane.study` 是否可註冊。
- 實體 iPhone／iPad 型號、最低 OS、可用儲存空間。
- GitHub Actions `macos-26` 目前提供 Xcode 26.6，CI 固定顯示實際 `xcodebuild -version`；runner image 更新時須再次核對。
- 題庫實際大小、圖片量與 JSON decode／search 記憶體表現。

## 不需為此專案安裝

Android Studio、Docker、資料庫伺服器、Web framework、CocoaPods、Fastlane、後端 runtime、遠端監控 SDK。未證明需要前不新增工具，降低維護與公開 supply-chain 面積。
